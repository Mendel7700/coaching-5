# Photos a ajouter

Depose ici les vraies photos de Dina et Tsipora.

Noms recommandes:

- `dina-nejar.jpg`
- `tsipora-sides.jpg`

Idealement:

- format vertical 4:5
- bonne lumiere naturelle ou studio
- fond sobre
- visage net
- photo professionnelle, chaleureuse, pas trop filtree

Quand les photos seront dans ce dossier, on pourra les copier dans `assets/` et remplacer les visuels temporaires du site.
